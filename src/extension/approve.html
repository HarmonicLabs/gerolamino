Gerolamino

browser node

Allow this site?

–

It asks to use your Gerolamino node:

  • read chain data (blocks, transactions, addresses, pools) answered by this node or its Gerolamo peer
  • see the node's tip, network and Trust checks
  • submit transactions that a wallet already signed

Gerolamino holds no keys: the site cannot sign or spend anything through it. You can remove the site later in Settings.
